# 법원 경매 → 실거래 → 현재 매물 연결 실험

2026-10-07 실행. 목표는 사용자가 관심 경매 물건의 가격을 실제 비교 가능한 근거로 판단하게 하는 것이다. 유료 공급 계약 없이 현재 연결된 국토부·네이버 Maps 키와 공개 페이지로 실험했다. 운영 DB에는 쓰지 않았다.

## 실제로 이어진 표본

| 구분 | 관측 내용 |
| --- | --- |
| 법원 물건 | 서울중앙지방법원 2023타경113350, 물건 1 |
| 대상 | 도곡렉슬 407동 9층 903호, 전유면적 119.8906㎡ |
| 최저매각가격 | 26억 5,600만원, 2026-10-08 기일 |
| 주소 연결 | 선릉로 221 → Maps 응답에서 도곡동 527 도곡렉슬아파트 확인 |
| 최신 비교 실거래 | 2026-08-12, 전용119.8906㎡, 5층, 41억 5,000만원, 동 미공개 |
| 현재 비교 매물 | 같은 단지 407동, 전용119.89㎡, 중층(9~16층), 호가42억 5,000만원, 남향 |
| 매물 조건 | 확인매물일 2026-09-15, 입주2026-11-14 협의 가능, 부동산뱅크 제공 |

법원 상세 목록내역에서 전유면적과 여러 지번을 확인했다. Maps 변환과 단지 주소를 함께 확인한 뒤 국토부 단지명·법정동·대표지번으로 연결했다. 이 표본의 연결은 검증했지만 전국 단지 식별을 일반화한 것은 아니다. 다필지 단지에서 대표지번이 달라지거나 단지명이 달라지면 별도 식별 규칙이 필요하다.

최저매각가격은 최신 실거래보다 36% 낮다. 이는 가격 간 산술 차이다. 거래 층·시점, 경매 권리·점유 조건과 최종 낙찰가가 달라 수익률이나 적정 입찰가를 의미하지 않는다. 매각물건명세서·현황조사서 원문 검토는 아직 하지 않았다. 공개 매물의 정확한 층·호가 확인되지 않아 경매 대상과 같은 집이라고 판단하지 않았다.

원문: [법원 검색 화면](https://www.courtauction.go.kr/pgj/index.on?w2xPath=/pgj/ui/pgj100/PGJ151F00.xml), [비교 매물 상세](https://fin.land.naver.com/articles/2649816342). 법원 링크는 영구 단건 링크가 아니므로 법원·사건·물건번호로 재조회한다.

매물21그룹은 고유 주택21채라는 뜻이 아니다. 네이버 화면에서도 여러 중개사의 등록을 한 그룹으로 보여준다. 호가를 합산 평균 내기 전에 매물 식별·중복 판단이 필요하다.

## 자동화 구성 제안

```text
법원 브라우저 수집 / 온비드 API 수집
  → 출처 원문·조회시각 저장
  → 법원+사건번호+물건번호로 식별, 묶음 자산 유지
  → 주소·단지·전유/토지/건물 면적 분리
  → 지번·좌표 변환
  → 국토부 지역+계약월 데이터 캐시 조회
  → 같은 단지·면적 우선, 부족하면 비교 범위를 명시해 확장
  → 현재 매물 검색·유효성·면적·조건 확인
  → 근거 목록과 차이를 각각 표시
```

1. 수집 작업: 법원 목록과 기존 진행 물건 상세를 나눠 확인한다. 변경된 최저가·일정·상태를 이력으로 보존한다. 실패한 페이지를 빈 결과로 확정하지 않는다. 페이지별 중복·전체 개수·완료 여부를 검사한다.
2. 실거래 작업: 경매 건마다 동일 지역·월 API를 다시 호출하지 않고 공유 캐시로 처리한다. 최신 몇 달을 재수집해 지연 신고·해제를 반영한다. 조회 전체 건수와 반환 건수가 다르면 다음 페이지를 받아야 하며 비교 자료 미완료를 표시한다.
3. 비교 작업: 동일 단지 식별을 먼저 하고 면적 유형별로 묶는다. 이번0.1㎡ 허용치는 소수점 표기 차이를 위한 실험값이며 전 유형에 확정 적용한 규칙이 아니다. 동 일치는 선택 조건으로 두고 층·동 차이를 공개한다. 최신순과 비교 적합성을 함께 제시한다.
4. 매물 작업: 관심 물건에 대해 필요한 비교 매물만 조회한다. 확인일·최근 열람시각·원문을 따로 저장하고 노출 종료를 재확인한다. 공급면적143.26㎡를 전용119.89㎡와 혼동하지 않는다. 가격과 출처 표시 조건도 운영 전 확인한다.
5. 서비스 표시: 최저입찰가·실거래·호가·기관 시세를 분리한다. 수집 실패·자료 없음·면적 미확인을 구별한다. 시세와 권리·점유 검토의 완료 상태를 따로 표시한다.

법원·네이버 브라우저 탐색은 이번에 에이전트가 실행한 자동 조작이다. 사용자 수동 입력은 없었지만, 무인 정기 실행 수집기가 완성된 것은 아니다. 국토부 수집과 분류는 재실행 가능한 Node 스크립트다. 드라이버의 지역·기간·물건은 이번 표본으로 고정돼 있다. 다음 구현은 이 값을 법원 파서 출력으로 공급하고, 브라우저 수집을 재시도·페이지 검증·작업 이력과 연결하는 것이다.

네이버 공개 페이지는 무단 복제·배포에 대한 제한을 표시한다. 이번 실험은 접근과 매칭 가능성을 확인한 것이며 서비스 재표시 권한 확보를 뜻하지 않는다. 가격·조건 수집 범위와 원문 링크 방식은 별도 운영 조건 검토 대상으로 남긴다.

## 재실행과 파일

- `node scripts/experiments/price-flow.mjs`: 법원 HTML1회와 국토부6개월 조회, XML 및 JSON 저장. 키는 기존 .env.local에서 읽고 출력하지 않는다.
- `node scripts/experiments/price-flow.mjs --offline`: 저장한 응답으로 매칭 재현. 새 API 호출 없음.
- `node scripts/experiments/geocode.mjs`: 공개 경매 주소2곳 변환.
- `node --test scripts/experiments/comparison.test.mjs`: 면적 불일치·거래 해제·잘못된 주소·날짜·가격·묶음 물건·갱신 누락7개 테스트 통과.
- `price-flow.json`: 실제 호출 결과와 원거래·비교 후보. `price-flow-replay.json`: 검증된 분류 함수로 재현한 결과.
- `browser-observations.json`: 법원 및 매물 화면의 관측 결과. `geocoding.json`: 좌표·주소 응답. `molit-*.xml`: API 원응답.

이번에 검증하지 못한 부분: 전국 법원 순회·전 페이지 완료·무인 반복 실행, 취하/기일 변경의 실시간 반영, 법원 서류 원문 분석, 비아파트 인근 비교, 기관 시세 자동 공급, 공개 서비스 재표시 조건. 모두 완료됐다고 표시하지 않는다.
