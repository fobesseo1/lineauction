단지·법정동·지번 동일, 면적 차이 0.1㎡ 이하, 해제 거래 제외. 동 일치 필수 아님. 최신 비교 거래 대비 36.0% 차이는 과거 거래가와 최저입찰가의 단순 산술값이며 수익률이나 확정 시세가 아니다. 비교 기간이 과거 실험의 202604~202609에서 현재 월 포함 202605~202610으로 이동하여 채택 거래가 6건에서 5건으로 바뀌었다.

최종 화면 검증에서 건물동(407동)을 법정동으로 취급하던 매퍼를 수정했다. 도곡동 등 실제 법정동으로 164개 물건의 지역 필드를 정규화했고 1,102개는 동일했다. 이 변경은 가격 변경이 아니며 물건·거래·가격이력 행수는 유지됐다. 검색은 1,266건 전체에 적용하고, 화면은 24건씩 추가 표시한다. 단지 검색과 24→48건 더 보기 동작을 브라우저에서 확인했다.

전국 60개 법원/지원의 목록을 공식 홈페이지 옵션에서 확인하고 순회 계획에 저장했다. 오늘 검증은 3개 법원이고 나머지 57개 법원은 미수집이다. 상세 원문은 기존 18건이며 나머지 상세 대기열을 처리해야 비교 가능 물건을 늘릴 수 있다. 현재 자동 매칭은 서울중앙 관할 6개 구의 아파트만 지원한다. 기타 유형과 전국 지역코드, 넓은 유사면적 비교는 후속 검증 범위다.

초기 연결의 확인되지 않은 자정 마감값은 현재 매퍼에서 제거했다. 이력 수정은 자동 승인 검토에서 거절됐으므로 원본을 유지하고 법원 이력 화면에는 마감시각 미확인으로 표시한다. 이력 1,751건에는 이 초기 연결 수정 관측이 포함돼 있으며 모두 실제 가격 변경을 의미하지 않는다.

DB 쓰기 실행 보고서는 `data/court/pipeline/latest.json`, 브라우저 실행별 원문은 `data/court/runs`, 재개 계획은 `npm run court:plan`. 운영 절차는 `docs/setup/court-pipeline.md`.
