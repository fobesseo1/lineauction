# 데이터 재배포 기준 (공개 API·MCP·다운로드용)

확인일: 2026-10-12. 법률 자문이 아니라 공개 자료를 바탕으로 정리한 내부 기준이다. 유료 API를 열기 전에는 변호사 확인을 받는다.

## 원천별 판단

| 원천 | 근거 | 재배포 |
|---|---|---|
| 법원경매정보 (사건번호, 소재지, 감정가, 최저가, 매각기일, 매각결과) | 대법원 저작권보호정책: 법원이 저작재산권 전부를 가진 자료는 저작권법 제24조의2(공공저작물 자유이용)로 이용 가능, **출처 표시 필수**, 링크 시 저작권보호정책 링크 요청 | ✅ 사실 항목은 출처·원문 링크와 함께 제공 |
| 법원 공개 사진 (현황조사·감정평가 사진) | 감정평가서 사진 등은 제3자(감정평가법인 등)의 저작물일 수 있음. 법원이 권리를 모두 가진다고 단정할 수 없음 | ⚠️ API·MCP·다운로드로는 **배포하지 않는다**. 화면 표시는 출처와 함께, API에는 법원 원문 링크만 |
| 온비드 공매 | 공공데이터포털 API, 이용허락범위 제한 없음 | ✅ 출처 표시 |
| 국토부 실거래, K-APT, 건축HUB | 공공데이터포털, 이용허락범위 제한 없음 | ✅ 출처 표시 |
| 브이월드 (공시가격, 공시지가, 토지이용계획, 필지 좌표) | 출처표시, 상업적 이용·변경 가능 (2차 저작물 작성 가능) | ✅ "출처: 국토교통부 브이월드" |
| 우리 계산값 (할인율, 참고 시세, 추천 점수, 통계, 매칭) | 자체 산출 | ✅ CC BY 4.0 등 우리 라이선스로 |

## 지킬 것

1. **출처 표시**: 응답마다 원천과 기준일을 넣는다. 법원 자료에는 대법원 저작권보호정책 링크(`https://www.scourt.go.kr/portal/popup/jeojak_pop.html`)와 법원경매정보 원문 링크를 함께 넣는다.
2. **사진은 링크만**: 공개 API·MCP 응답에는 사진 파일이나 우리 저장소의 사진 주소를 넣지 않는다.
3. **개인정보 제외**: 소유자, 채권자, 임차인 이름은 수집하지도 내보내지도 않는다. 사건번호와 소재지는 법원이 공개한 사실이라 포함한다.
4. **원자료 대량 덤프 금지**: 법원 원본을 통째로 내려받게 하지 않는다. 검색·요약 단위로 제공하고 호출 한도(rate limit)를 둔다. 통계와 계산값은 CSV로 제공해도 된다.
5. **우리 DB 보호**: 우리 결과물(매칭, 할인율 등)에는 라이선스와 출처 표기 조건을 명시한다. 남이 통째로 긁어가는 것은 이용약관으로 금지한다. 판례상 가공·편집한 DB는 데이터베이스제작자 보호를 받을 수 있다.
