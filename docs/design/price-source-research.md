# 선경매 가격 자료 확보 경로

확인일: 2026-10-07. 공개 상품 안내와 공식 기술문서 조사 결과다. API 상품 존재, 실제 호출 성공, 서비스 화면 재표시 허용은 별도 검증 단계다. 아래 신규 공급사의 인증 호출·계약·결제는 진행하지 않았다.

## 목적

관심 경매 물건에 대해 국토부 실제 거래와 함께 사용자가 알아볼 수 있는 기관의 참고 시세 및 현재 매물을 제시한다. 단순히 기관 이름을 붙이는 데 그치지 않고 원출처, 가격 성격, 기준일, 비교 면적과 원문을 확인할 수 있어야 한다.

## 확인한 경로

### KB부동산: 우선 검증 후보

- KB 공식 공개 페이지에서 단지별 시세와 매물평균가를 확인했다. 테스트 실거래 단지인 일원동 푸른마을도 공개 페이지가 있다: https://kbland.kr/se/c/130
- 페이지에 여러 면적 유형이 있으므로 기본 표시 금액을 국토부 전용 84.93㎡ 거래와 곧바로 비교하지 않는다. 단지와 전용면적 유형을 모두 확인해야 한다.
- HYPHEN의 현재 부동산정보 조회 상품에는 KB 단지 코드 및 면적별 가격 조회가 안내돼 있다: https://hyphen.im/product/view?seq=9
- 이 상품은 원기관이 직접 제공하는 공개 API가 아니라 스크래핑 기반 중계 상품이다. TR슬림 안내 요금은 월 멤버십 10만원에 호출별 요금이 추가된다. 테스트베드 안내는 있으나 실제 시세 테스트 접근과 건별 단가는 미확인이다.
- 공급사에 공개 웹서비스 가격 표시, 저장·갱신, 출처 표시 및 원출처 이용 권한 범위를 먼저 확인한다. 유료 상품이라는 사실만으로 재표시 권한이 확보됐다고 판단하지 않는다.

### 한국부동산원 부동산테크: 기관 시세 후보

- 공식 서비스는 공동주택과 오피스텔 시세를 안내한다: https://www.rtech.or.kr/portal/intro/intro.do
- 상·하위 평균가는 해당 기관의 정의에 따라 표시한다. 거래 최고가·최저가로 바꿔 설명하지 않는다.
- 앞의 HYPHEN 상품에도 부동산테크 시세 조회가 있다. 다만 원사이트는 자동화 대량 수집과 상업적 재배포 제한을 명시한다: https://www.rtech.or.kr/portal/main/indexPage.do
- 따라서 기관의 정보 제공 담당 또는 공급사와 허용 가능한 공급 방식을 확인해야 한다. 담당 부서 안내: https://www.reb.or.kr/reb/jo/jobshare/selectJobShareView.do?mi=10023
- R-ONE 공개 API도 있지만 지역 통계용이다. 개별 아파트 면적별 시세 공급 API로 취급하지 않는다: https://www.reb.or.kr/r-one/portal/openapi/openApiDevPage.do

### 빅밸류: 민간 AI 추정 시세 API 후보

- 공식 문서에서 건축물 시세 API의 요청과 응답 규격을 확인했다: https://docs.bigvalue.ai/data/data/building/building-sise/
- 단지·동·호 식별자, 도로명주소 관리번호 또는 필지 식별자로 조회하는 POST API이며 기준년월을 지정한다. 응답 규격에 전용면적, 추정 시세·범위, 등급이 있다.
- 실제 거래나 KB 시세와 구분하여 ‘빅밸류 AI 추정 시세’로 표시한다. 문서 예제 금액을 실제 조회 결과로 사용하지 않는다.
- 건물 유형별 제공 범위, 실제 표본 반환율, 요금, 최신 기준월 및 외부 화면 제공 조건은 상담·테스트로 확인해야 한다. 문서 공개를 무료 호출 가능으로 해석하지 않는다.

### 파일 다운로드: API 외의 확보 방법

- 한국부동산원 부동산 빅데이터 플랫폼에 디스코의 서울 일반건축물 시세·공시지가 파일 상품이 무료로 안내된다: https://www.bigdata-realestate.kr/rebpp/usr/prd/prdInfoDetail.do?req_productId=95
- 플랫폼 운영기관과 데이터 생산자는 다르다. 이 자료를 ‘한국부동산원 공식 시세’라고 표시하면 안 된다.
- 확인한 목록의 최신 기준은 2025년 1분기다. 파일 내용을 다운로드 검증하지 않았으며 현재 가격 판단에 바로 사용할 수 없다. 갱신 여부·내용·재사용 조건 확인 대상으로 남긴다.

## 네이버 부동산의 위치

이번 조사에서는 일반 개발자가 신청해 범용 주택 매물과 가격을 공급받는 네이버 공식 공개 API를 확인하지 못했다. Maps 인증키는 매물 데이터 공급 권한이 아니다. HYPHEN에는 네이버 단지 및 사무실·상가 정보 상품이 있으나 모든 주택 매물의 호가·조건을 받을 수 있다는 근거로 확대하지 않는다.

자동 공급이 검증되기 전에는 확인된 단지 원문 링크로 직접 확인하는 경로를 제공할 수 있다. 매물평균가 한 숫자만으로 개별 매물의 층·면적·입주 조건까지 비교한 것처럼 표시하지 않는다.

## 선경매 화면의 제안

1. 경매·공매 최저입찰가와 매각 범위를 표시한다.
2. 국토부 실제 거래 목록에서 같은 단지와 유사 전용면적을 우선 확인한다. 비아파트는 용도·위치·면적 등 비교 조건을 공개한다.
3. 연결 가능한 KB 또는 한국부동산원 시세를 출처와 기준일, 해당 면적 유형과 함께 별도로 표시한다.
4. 현재 매물은 호가와 조건 및 확인일, 원문을 보여준다. 민간 AI 추정가는 별도 표기한다.

각 출처와 최저입찰가의 차이를 각각 계산하며 서로 다른 가격 종류를 합쳐 하나의 평균 시세로 만들지 않는다. 자료가 없거나 대상 면적이 확인되지 않으면 미확인 상태를 표시한다. 기관 이름·로고가 제휴나 보증을 암시하지 않도록 한다.

## 다음 검증에 필요한 공급사 질문

- 선경매 이용자에게 시세 금액과 출처를 표시할 수 있는가? 원출처 이용 범위는 어떻게 확보되는가?
- 서버 저장, 이력 보관, 갱신 간격과 계약 종료 후 처리 조건은 무엇인가?
- 주소 → 단지 → 전용면적 식별이 가능한가? 아파트·오피스텔·연립·단독 등 제공 범위는 어디까지인가?
- 실제 데이터로 테스트 가능한가? 기준일과 제공 누락을 반환하는가?
- 월 기본비용과 호출 단가, 테스트 비용은 얼마인가?

우선순위 제안: KB 면적별 시세 공급 가능성을 먼저 검증하고, 부동산테크를 병행 검토한다. 비아파트는 빅밸류를 추가 후보로 둔다. 법원 경매 확보 조사는 별도 문서 data-sourcing-options.md에서 계속 관리한다.
